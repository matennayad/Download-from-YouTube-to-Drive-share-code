# הקמת פרוקסי על המחשב הביתי (10 דקות)

## מה צריך

- מחשב Windows עם אינטרנט ביתי רגיל (**בלי NetFree!**)
- המחשב יישאר דלוק (מסך יכול להיות כבוי)

## שלב 1: הורדת 3proxy

1. היכנס ל-https://github.com/3proxy/3proxy/releases
2. הורד את קובץ ה-zip האחרון עבור Windows (למשל `3proxy-0.9.4-x64.zip`)
3. פתח את הקובץ לתיקייה `C:\3proxy`
4. העתק לשם גם את `3proxy.cfg`, `run-proxy.bat`, ו-`test-proxy.bat` מהתיקייה הזאת

## שלב 2: הגדרת סיסמה

1. פתח את `C:\3proxy\3proxy.cfg` בפנקס רשימות
2. החלף `סיסמה_חזקה_כאן` בסיסמה ארוכה ואקראית (שמור אותה - תצטרך אותה מיד)

## שלב 3: הרצה ובדיקה מקומית

1. הרץ `run-proxy.bat` (אם Windows חוסם - "More info" → "Run anyway")
2. הרץ `test-proxy.bat`, הזן את הסיסמה
3. **מצופה:**
   - בדיקה 1: מופיע ה-IP הציבורי של הבית
   - בדיקה 2: `HTTP: 200` מאתר כאן
   - בדיקה 3: `HTTP: 200` (או 302) מה-CDN

אם הכל ירוק — הפרוקסי עובד מקומית. עוברים לחשיפה לאינטרנט.

## שלב 4: פתיחת הפורט בנתב

1. מצא את ה-IP הפנימי של המחשב: הרץ `ipconfig` וחפש "IPv4 Address" (למשל 192.168.1.105)
2. היכנס לנתב (בדרך כלל http://192.168.1.1 או http://192.168.0.1 — הסיסמה על המדבקה בתחתית)
3. מצא "Port Forwarding" / "Virtual Server" / "הפניית פורטים"
4. הוסף כלל: **פורט חיצוני 3128 → פנימי 3128 → IP הפנימי של המחשב**
5. שמור

## שלב 5: חשיפה לחומת האש של Windows

1. התחל → "Windows Defender Firewall with Advanced Security"
2. Inbound Rules → New Rule → Port → TCP 3128 → Allow

## שלב 6: בדיקה מבחוץ

1. מצא את ה-IP הציבורי של הבית (מהבדיקה 1 למעלה, או חפש "what is my ip")
2. **מהטלפון (עם אינטרנט סלולרי, לא וויפי הביתי)** — הורד אפליקציית בדיקת פורט או השתמש באתר https://portchecker.co מהטלפון: הזן את ה-IP הציבורי + פורט 3128
3. אמור להיות "open"

## שלב 7: חיבור ל-Railway

אם ה-IP הביתי שלך קבוע (נפוץ יחסית ב-Bezeq) — פשוט:

היכנס ל-Railway → הפרויקט → Variables → הוסף:

```
KAN_PROXY_URL = http://admin:הסיסמה@ה-IP-הציבורי:3128
```

אם ה-IP מתחלף — הקם דומיין קבוע (DDNS):

1. הירשם ב-https://www.duckdns.org (חינם, התחברות עם גוגל)
2. צור דומיין, למשל `my-proxy.duckdns.org`
3. הורד את סקריפט העדכון שלהם ל-Windows וקבע אותו ב-Task Scheduler (כל 5 דקות)
4. הגדר ב-Railway:

```
KAN_PROXY_URL = http://admin:הסיסמה@my-proxy.duckdns.org:3128
```

## שלב 8: הפעלה אוטומטית עם הפעלת המחשב

1. Win+R → הקלד `shell:startup` → Enter
2. צור קיצור דרך ל-`run-proxy.bat` בתיקייה שנפתחה

## שלב 9: הבדיקה הסופית

בגיטהאב: **Actions → Test KAN Series Download → Run workflow**

- target: `railway`
- mode: `download`
- kan_url: `https://www.kan.org.il/content/kan/kan-11/p-11843/s8/756427/`

אם הכל תקין — הפרק יורד ויועלה לדרייב. 🎉

## פתרון בעיות

| בעיה | פתרון |
|---|---|
| בדיקה 1 נכשלת | הפרוקסי לא רץ — ודא ש-run-proxy.bat פתוח |
| בדיקה 2 נכשלת (000) | הרשת בבית חוסמת? בדוק שזה לא NetFree דרך הספק |
| פורט סגור מבחוץ | הנתב לא מפנה — נסה CGNAT: אם ה-IP הציבורי מתחיל ב-10. / 100.64. — פנה לספק ל-IP אמיתי |
| Railway לא מצליח להתחבר | הסיסמה ב-KAN_PROXY_URL עם תווים מיוחדים? קודד אותם (%40 במקום @) |
| הכל עובד ואז נעצר | המחשב נכבה/נרדם — בטל שינה: הגדרות → חשמל → "לעולם לא בשינה" |
