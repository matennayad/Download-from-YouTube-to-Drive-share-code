# 🖼️ תמונות גמיני לדרייב — מדריך הפעלה

כל תמונה שגמיני יוצר ב-gemini.google.com נשלחת אוטומטית לשרת החיצוני
(Railway), ומשם מועלית לדרייב. התוצאה: התמונות מופיעות אצלך בתיקיית
**"תמונות גמיני"** בדרייב — ולא רק בהתכתבות עם גמיני.

---

## 🔗 איך זה עובד

```
gemini.google.com          Apps Script (Web App)          שרת Flask            Drive
┌────────────────┐        ┌────────────────────┐         ┌─────────────┐      ┌────────┐
│ תוסף דפדפן     │ ─────▶ │ אימות מכשיר +      │ ──────▶ │ POST        │ ───▶ │ תיקיית │
│ (Tampermonkey) │        │ מכסה שעתית,        │         │ /gemini-    │      │ תמונות │
│ סורק את העמוד  │        │ העברת התמונה       │         │ image       │      │ גמיני  │
└────────────────┘        └────────────────────┘         └─────────────┘      └────────┘
```

1. התוסף סורק את העמוד כל 2.5 שניות ומזהה תמונות שנוצרו על ידי גמיני
   (תמונות גדולות בתוך בלוק התשובה של המודל — לא אייקונים, לא אווטארים,
   ולא תמונות שהמשתמש עצמו העלה).
2. כל תמונה מורדת בדפדפן ל-base64 ונשלחת לאותו Web App של Apps Script
   שמשמש את תוסף היוטיוב — כולל אותו אימות מכשיר (קוד למייל בפעם
   הראשונה) ואותו לוג בגיליון.
3. ה-Apps Script מאמת, בודק מכסה שעתית (10 תמונות לשעה למשתמש, נפרדת
   ממכסת ההורדות), ומעביר את התמונה לשרת — endpoint חדש `/gemini-image`.
4. השרת מעלה את התמונה לדרייב עם אותם פרטי OAuth שמשמשים להורדות
   הווידאו, לתיקיית "תמונות גמיני" בשורש הדרייב (נוצרת אוטומטית).
5. טוסט ירוק מופיע בעמוד גמיני עם קישור "פתח בדרייב" לכל תמונה שעלתה.

שם הקובץ בדרייב: `גמיני - <ההנחיה> - <תאריך ושעה>.png`.

---

## 📦 מה נוסף בריפו

| קובץ | מה שינוי |
|---|---|
| `Gemini Images to Drive.user.js` | חדש — התוסף ל-gemini.google.com |
| `app.py` | endpoint חדש `POST /gemini-image` (base64 או URL → דרייב) |
| `apps-script/Code.gs` | פעולה חדשה `uploadGeminiImage` + handler |
| `API_GUIDE.md` | תיעוד ה-endpoint החדש |

## 🚀 הפעלה (3 צעדים)

### 1. השרת (Railway/Render)

פשוט דחפו את `app.py` — אין משתני סביבה חדשים נדרשים. אופציונלי:

- `GEMINI_IMAGE_MAX_BYTES` — תקרת גודל תמונה (ברירת מחדל 20MB).

### 2. Apps Script

פתחו את הפרויקט של ה-Web App הקיים (script.google.com — אותו פרויקט
של תוסף היוטיוב), הדביקו את `Code.gs` המעודכן, ופרסמו גרסה חדשה:
**Deploy → Manage deployments → Edit → New version → Deploy**.

> ⚠️ בלי פריסה מחדש התוסף יקבל תשובה שאינה JSON ויודיע על כך בטוסט.

### 3. התוסף בדפדפן

1. התקינו את הקובץ `Gemini Images to Drive.user.js` ב-Tampermonkey
   (דרך Utilities → Import, או פשוט פתחו את הקובץ והדביקו בסקריפט חדש).
2. פתחו gemini.google.com — יופיע כפתור 🖼️ צף בפינה השמאלית התחתונה.
3. לחצו עליו, הזינו את כתובת המייל המאושרת שלכם, ואשרו עם הקוד
   שמגיע למייל (בפעם הראשונה בלבד).
4. בקשו מגמיני ליצור תמונה — ברגע שהיא מופיעה, היא תעלה לדרייב
   אוטומטית ותופיע בטוסט עם קישור.

---

## ⚙️ מצבי הפעלה

- **העלאה אוטומטית (ברירת מחדל: פעילה)** — כל תמונה שמזוהה נשלחת מיד.
- **כבויה** — התמונות נאספות לתור (עד 20) ומועלות רק בלחיצה על
  "העלה תמונות שנאספו עכשיו". המצב נשמר בין רענונים.

תמונות שנאספו לפני האימות מועלות מיד אחרי אימות מוצלח — שווה לאמת
מוקדם, לפני שמתחילים לייצר תמונות.

---

## 🛡️ מה מוגן

- **אימות מכשיר** — אותו מנגנון של תוסף היוטיוב: מייל מאושר + קוד
  חד-פעמי + טוקן מכשיר. משתמש חסום נחסם גם כאן.
- **מכסה שעתית נפרדת** — 10 תמונות לשעה למשתמש (מעל מכסת ההורדות),
  ורישום מלא בגיליון "תגובות לטופס 1" וב"לוג שגיאות ובקשות".
- **X-API-KEY** — השרת מקבל בקשות רק מה-Apps Script עם המפתח.
- **תקרת גודל** — 20MB לתמונה בשרת, 12MB payload ב-Apps Script.
- **מניעת כפילויות** — כל תמונה מזוהה לפי תוכנה; אותה תמונה לא תעלה
  פעמיים באותו סשן, גם אם גמיני מציג אותה שוב.
- **הגבלת ניסיונות** — תמונה שנכשלת 5 פעמים מושמטת; אימות שקט מוגבל
  לפעם בדקה כדי שכשל רשת לא יהפוך להצפה.
