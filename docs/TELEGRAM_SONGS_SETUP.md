# 🎵 שירים מטלגרם ל-Drive - אוטומטי

דימון שרץ על השרת שלך (ריוולי), עוקב אחרי ערוצי טלגרם ציבוריים,
וכל שיר חדש שעולה בהם יורד לשרת ומעלה ל-Drive. **אתה לא צריך להיכנס
לטלגרם שוב.** אפשר גם שישלח לך את קישור ה-Drive ישר לצ'אט בטלגרם.

> 💡 יש מסלול שני, פשוט בהרבה: להפוך את **הבוט עצמו** למנהל בערוץ —
> בלי סשן, בלי api_id/api_hash, בלי מספר טלפון. מגבלה אחת: קבצים
> עד 20MB ופוסטים מסוג אודיו בלבד. המדריך: `TELEGRAM_CHANNEL_SETUP.md`.

---

## איך זה עובד (מהיר)

1. השרת מתחבר לטלגרם פעם אחת עם "סשן" — הרשאה שאתה יוצר מהמחשב שלך
   בפקודה אחת (רגע, מסבירים).
2. מאז, כל שתי דקות בערך השרת בודק אם עלה שיר חדש בערוצים שבחרת.
3. שיר חדש? יורד לשרת, מעלה ל-Drive, ונמחק מהשרת. המצב נשמר כדי
   שאף שיר לא יורד פעמיים.
4. אם הגדרת chat לנוטיפיקציות — תקבל בטלגרם הודעה עם קישור לשיר
   ב-Drive.

---

## שלב 1: מקבלים api_id ו-api_hash (פעם אחת בחיים)

1. תיכנס ל-[my.telegram.org](https://my.telegram.org) עם מספר הטלפון
   שלך (הקוד מגיע לטלגרם עצמו, לא ב-SMS).
2. תיכנס ל-**API development tools**.
3. תמלא שם אפליקציה כלשהי (שם + שם קצר, למשל "mysongs" / "songs").
4. תעתיק את **app_api_id** (מספר) ואת **app_api_hash** (מחרוזת).

> אלה לא סיסמה לחשבון שלך — זה מזהה של אפליקציית צד שלישי שבבעלותך.
> זה חוקי לגמרי וזה אותו מנגנון שכל אפליקציית טלגרם משתמשת בו.

---

## שלב 2: יוצרים את הסשן (פעם אחת, מהמחשב שלך)

הסשן = "כניסה לטלגרם" ששמורה כמחרוזת. יוצרים אותה פעם אחת ומדביקים
לריוולי כ-Secret.

אם יש לך פייתון במחשב:

```bash
pip install telethon

# Windows (PowerShell):
$env:TELEGRAM_API_ID="המספר_שלך"
$env:TELEGRAM_API_HASH="המחרוזת_שלך"
python telegram_songs_to_drive.py --login

# Mac / Linux:
export TELEGRAM_API_ID=המספר_שלך
export TELEGRAM_API_HASH=המחרוזת_שלך
python3 telegram_songs_to_drive.py --login
```

הסקריפט ישאל מספר טלפון + קוד שמגיע לטלגרם (ולפעמים גם סיסמת 2FA).
בסוף יודפס משהו כזה:

```
TELEGRAM_SESSION_STRING=1BQANOTEuMTA4Lmcu...ארוך מאוד...
```

**תעתיק את כל המחרוזת.**

> ⚠️ המחרוזת הזאת = גישה מלאה לחשבון הטלגרם שלך. שומרים רק ב-Secrets
> של ריוולי, לא בגיט ולא בצ'אט.

טיפ: כדאי להשתמש בכתובת מייל/חשבון טלגרם ייעודי, או לפחות לדעת
שאפשר לבטל את הסשן בכל רגע מהגדרות → מכשירים בטלגרם.

## שלב 3: Secrets בריוולי

בריוולי: **Tools → Secrets** (מפתח → ערך):

| מפתח | ערך |
|---|---|
| `TELEGRAM_API_ID` | המספר משלב 1 |
| `TELEGRAM_API_HASH` | המחרוזת משלב 1 |
| `TELEGRAM_SESSION_STRING` | המחרוזת הארוכה משלב 2 |
| `TELEGRAM_CHANNELS` | ערוצים מופרדים בפסיק, למשל `@songs,@hebrew_music` (אפשר גם כתובות מלאות: `https://t.me/s/songs`) |
| `TELEGRAM_NOTIFY_CHAT` | (אופציונלי) ה-@username שלך או chat_id מספרי — לקבל קישורי Drive בטלגרם |

בנוסף צריך שיהיו כבר מוגדרים (כנראה כבר קיימים אצלך בשביל app.py):

| מפתח | למה |
|---|---|
| `GOOGLE_OAUTH_CLIENT_ID` / `SECRET` / `REFRESH_TOKEN` | העלאה ל-Drive |
| `DRIVE_FOLDER_ID` | לאיזו תיקייה להעלות (אופציונלי — בלי זה ייכנס לשורש ה-Drive) |

**זהו.** מהרגע הזה, כשהשרת עולה (Deploy) — הדימון קם אוטומטית לצד
השרת. בלי הסודות האלה — השרת מתנהג בדיוק כמו קודם.

היכנס ללוגים (Console) ותראה:

```
[tg-watcher] ערוצים במעקב: @songs, @hebrew_music
[tg-watcher] מחובר כ: ...
[tg-watcher] Health server: http://0.0.0.0:8081
```

## שלב 4 (מומלץ בריוולי): שהשרת לא יירדם

ריוולי שם Repls ב"שינה" כשאין תעבורה — ואז אין מי שמקשיב לערוץ.
אם יש לך **Deployments** (בתשלום או Reserved VM) — אין בעיה, זה רץ
תמיד.

אם אין — שתי דרכים פשוטות:

- **UptimeRobot** (חינם): מוניטור HTTP כל 5 דקות על כתובת ה-Repl
  שלך. הפינג שומר את ה-Repl ער.
- פינג קבוע מכל שירות אחר שיש לך (cron-job.org וכדומה).

## מה מורידים (ברירות מחדל)

- ✅ קבצי **שמע** (מה שמוגדר כ-music/audio בטלגרם)
- ❌ הודעות קול (`voice`) — כדי להפעיל: Secret
  `TELEGRAM_DOWNLOAD_VOICE=1`
- ❌ וידאו — כדי להפעיל: Secret `TELEGRAM_DOWNLOAD_VIDEO=1`
- ❌ תמונות, טקסט, מסמכים, מדבקות — לעולם לא

עוד משתני כוונון (כולם אופציונליים):

| מפתח | ברירת מחדל | מה זה |
|---|---|---|
| `TELEGRAM_POLL_SECONDS` | `120` | כמה שניות בין בדיקות |
| `TELEGRAM_POLL_LIMIT` | `50` | כמה הודעות למשוך בכל בדיקה |
| `TELEGRAM_BACKFILL` | `0` | בהפעלה ראשונה: כמה שירים ישנים להוריד (0 = רק מהיום והלאה) |
| `TELEGRAM_HEALTH_PORT` | `8081` | פורט לניטור (0 = כבוי) |
| `TELEGRAM_SONGS_STATE_FILE` | `/tmp/...` | קובץ מצב (ריוולי: השאר ב-/tmp, זה בסדר) |

## ניטור

הדימון מאזין על פורט 8081 בפנים הקונטיינר. בריוולי אין גישה ישירה
לפורט הזה (רק 443→הפורט הראשי), אז בינתיים המצב נראה בלוגים. אם תרצה
אפשר להוסיף route של Flask (`/telegram-status`) שמחזיר את ה-JSON
הזה — תגיד.

בלוגים תראה לכל שיר:

```
[tg-watcher] [songs] msg 1234: downloading audio (8123 KB) -> אמן - שיר.mp3
[tg-watcher] [songs] msg 1234: uploaded -> https://drive.google.com/file/d/...
```

## שאלות נפוצות

**זה חוקי?**
הורדת קבצים מערוצים ציבוריים שאתה יכול לקרוא בכל דפדפן — זה אותו
דבר כמו לשמור קובץ ידנית. זכויות היוצרים של השירים עצמם הן על היוצרים;
שימוש פרטי, כרגיל.

**האם טלגרם יחסם אותי?**
הסקריפט בודק פעמיים בדקה — עדין מאוד. יש גם טיפול אוטומטי
ב-FloodWait (כשטלגרם מבקש המתנה, הוא ממתין).

**מה קורה אם השרת נופל באמצע הורדה?**
קובץ המצב נשמר רק אחרי הצלחה מלאה (העלאה ל-Drive). אם נפל באמצע —
בעלייה מחדש השיר יירד שוב. אין מצב של שיר "אבוד".

**רוצה לעצור?**
פשוט תמחק את Secrets ה-TELEGRAM_*. השרת יעלה בלי הדימון.
כדי לבטל גישה: טלגרם → הגדרות → מכשירים → הפעלה של המכשיר
"songs-to-drive" → Terminate.

**שם הקובץ ב-Drive נקבע איך?**
בסדר: "מבצע - כותרת" מתכונות השמע → שם הקובץ המקורי → שורה ראשונה
בטקסט ההודעה → תאריך. שמות כפולים מקבלים סיומת " (2)".
