המפתח הראשי. אותו ערך נכנס ל-Railway ולסקריפט.

הקבצים המוכנים שלך

נבנים אוטומטית מהערכים שמילאתם. אין צורך לפתוח קבצים או לערוך קוד.

✨בכל שלב במדריך יש כרטיס קובץ. לוחצים 📋 העתק קוד מוכן, ומדביקים בעורך במקום כל התוכן (Ctrl+A ואז Ctrl+V). הכרטיס מראה ✓ כשכל הערכים בפנים, ו-⚠ עם שם הערך שעוד חסר בפאנל.
🔐הקבצים המוכנים כוללים את המפתח שלכם. מדביקים אותם רק ב-Apps Script וב-Tampermonkey, ולא מעלים אותם לגיטהאב.

קבלת הקוד והעלאה לגיטהאב שלכם חובה

כ-5 דקות

1א. איפה הקבצים

  • קיבלתם קישור למאגר בגיטהאב? בעמוד המאגר: כפתור ירוק Code → Download ZIP, ואז קליק ימני על הקובץ שירד → חלץ הכל. תיווצר תיקייה ששמה מסתיים ב--main.
  • קיבלתם קובץ zip? מחלצים אותו, ותיווצר תיקייה בשם yt-drive-system.

זה מה שיש בתוך התיקייה שחולצה:

📁 (התיקייה שחולצה)
🌐 guide.htmlהמדריך הזה
📁 download-serviceהשרת. Railway מושך את הקוד מכאן (שלב 2)
📁 apps-scriptסקריפטים של גוגל
📁 downloadsסקריפט ההורדות (שלב 4): Code.gs · channels.gs · appsscript.json
📁 unified-searchטופס החיפוש (שלב 6): קוד.js · admin_dashboard.html · appsscript.json

💡את הקבצים שבתיקיות apps-script ו-userscripts לא צריך לפתוח בכלל. הם מובנים בתוך המדריך, וכפתורי "העתק קוד מוכן" נותנים אותם כבר עם הערכים שלכם.

1ב. העלאת הקוד לגיטהאב שלכם (בשביל Railway)

אפשרות א' (הכי פשוט): Fork מומלץ

  1. נכנסים לעמוד המאגר שקיבלתם, ולוחצים Fork (למעלה, ליד Star).
  2. Create fork. זהו, עותק של כל הקוד נמצא עכשיו בחשבון שלכם.

אפשרות ב': העלאה ידנית

  1. פותחים מאגר חדש. רצוי לבחור Private, ולא לסמן "Add a README".
    🐙 יצירת מאגר חדש ↗
  2. במאגר החדש לוחצים uploading an existing file.
  3. פותחים במחשב את התיקייה שחולצה, נכנסים לתוכה, מסמנים הכל (Ctrl+A: התיקיות download-service, apps-script וכל השאר), גוררים לחלון הגיטהאב, ולוחצים Commit changes. את התיקייה החיצונית עצמה לא גוררים.
⚠️הכי חשוב שהתיקייה download-service תופיע ישירות בעמוד הראשי של המאגר. את התיקייה הנסתרת .github לפעמים לא רואים בגרירה; היא לא חובה.
למתקדמים: העלאה עם git
Terminal · מתוך התיקייה שחולצה
git init && git add . && git commit -m "initial"
git branch -M main
git remote add origin https://github.com/YOUR_USER/YOUR_REPO.git
git push -u origin main

השרת מחזיר unauthorized
API_KEY ב-Railway וב-Code.gs חייבים להיות זהים לגמרי, בלי רווח בהתחלה או בסוף. אחרי שינוי ב-Railway, ממתינים שהשרת יעלה מחדש.

  
שגיאת דרייב / invalid_grant / "גשר הטוקנים"
בודקים ש-DRIVE_TOKEN_BRIDGE_URL זהה לכתובת ה-Web App, שהפריסה היא "Execute as: Me" ו-"Anyone", ושהערך של API_KEY זהה בשני הצדדים. בדיקה: ‎/?drive=1.

  
הטופס לא מעובד, והסטטוס בגיליון לא מתעדכן
הלשוניות חייבות להיקרא בדיוק תגובות לטופס 1 ו-מאושרים. מריצים __הצג_טריגרים_פעילים כדי לוודא שיש טריגרים, ואם צריך מריצים שוב __התקן_טריגר_סריקת_ערוצים. בטבלת התשובות צריכות להיות בדיוק 3 עמודות אחרי חותמת הזמן.

  
"לא מאושר" או "נגמרה המכסה"
המייל שבטופס צריך להיות זהה למה שכתוב בעמודה A של "מאושרים". בעמודה B צריכה להיות מכסה (מספר או ללא הגבלה), או מכסה יומית בעמודה C.

  
מיילים לא מגיעים
מריצים __בדוק_שליחת_מייל ובודקים בתיקיית הספאם. בלי Gmail API המכסה היא 100 מיילים ביום (ראו את ההרחבה בשלב 4).
